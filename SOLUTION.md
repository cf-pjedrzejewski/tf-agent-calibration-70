# Calibration Solution

The pull request workflow uses Claude Code because it can edit files and run
Terraform in a tool loop. The prompt reads the custom definition at
`.github/agents/terraform-test-agent.md`, which loads
`.github/skills/terraform-test/SKILL.md`. The skill supplies test-authoring and
verification steps. Read, Glob, Grep, Edit, Write and Terraform Bash commands
are explicitly allowed.

Configure `ANTHROPIC_API_KEY` as a repository secret, then open a same-repository
PR changing a module. The workflow installs Terraform 1.9.8. It supplies a diff,
asks the agent to update tests, runs them and uploads a report. A separate job
with PR write permission comments with results and proposed test contents.
Copying test contents is manual: this avoids granting the agent a push token,
but the workflow does not commit its proposed changes.

The function-app HTTPS test was carried forward from the first calibration
candidate, not generated by a recorded run of this workflow. It mocks providers
and overrides the external build-info data source. No end-to-end agent run or
example PR is provided. Mocked tests do not prove Azure accepts the configuration.

The agent has three test attempts per module, 30 turns and a 15-minute job
timeout. Haiku is selected to keep costs low for a small repository. The report
job posts unresolved failures and a fallback comment if the agent produces no
report. Comments accumulate rather than updating an earlier report.

Fork PRs are skipped because they cannot access the model secret. No Azure
credentials are configured. The agent has a read-only GitHub token and is told
to treat PR content as data. File-edit restrictions are instructions, not a
filesystem sandbox. The model API key still shares the agent/test job: this is
not an adequate isolation boundary for untrusted contributors. This example is
only for maintainer-controlled branches. No model secret is configured in this
calibration repository.

Actions use version tags for a compact prototype; a production deployment would
pin reviewed commit SHAs to avoid tag movement. Broader test coverage and safer
isolation are not implemented here.
